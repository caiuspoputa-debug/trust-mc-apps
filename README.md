# Distribuție TRUST MC

Pagina de instalare Android/iPhone și APK-ul criptat sunt independente de site-ul de prezentare.

- Instalare: https://caiuspoputa-debug.github.io/trust-mc-apps/descarca/
- Aplicație web în funcțiune: https://trust-mc-web.peachywave5.chatgpt.site/
- Surse web: https://github.com/caiuspoputa-debug/trust-mc-web

Parola APK nu este stocată în acest depozit. Înlocuirea versiunii Android se face prin actualizarea fișierului criptat și a manifestului împreună. Nu publicați APK-ul necriptat dacă doriți să păstrați parola la descărcare.

Site-ul transmite parametrii `lang` și `site`. Linkul de întoarcere acceptă numai prezentarea GitHub existentă sau rădăcinile HTTPS mctrust.ro / www.mctrust.ro; nu permite adrese arbitrare. Astfel funcționează și după mutarea prezentării, fără editarea paginii de instalare.

Compatibilitate: până la migrarea updaterului din APK-urile instalate, manifestul și fișierul criptat trebuie publicate și în vechiul /trust-mc-romania/descarca/. Noua pagină este adresa principală pentru distribuție.
